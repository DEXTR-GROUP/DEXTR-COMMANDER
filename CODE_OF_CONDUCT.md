# Code of Conduct

## Purpose

DEXTR Commander is an engineering project. Contributions, reviews, and discussions should remain professional, technical, and evidence-driven.

## Expected behavior

Participants should:
- communicate respectfully;
- focus criticism on code, documentation, designs, and technical claims;
- provide reproducible evidence for defects where possible;
- respect project maintainers and other contributors;
- disclose relevant security concerns responsibly.

## Unacceptable behavior

Harassment, threats, discrimination, personal attacks, deliberate disruption, publication of private information, and malicious disclosure of security-sensitive information are not acceptable.

## Enforcement

Project maintainers may moderate discussions, remove content, or restrict participation when necessary to keep project collaboration constructive and secure.
