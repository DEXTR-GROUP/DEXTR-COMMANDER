# Установка DEXTR Commander

## Установка готового релиза

Для обычного пользователя рекомендуется устанавливать готовый файл релиза, а не собирать проект из исходников.

После загрузки и проверки файла:

```bash
chmod +x install.sh
sudo ./install.sh
```

Установщик:

1. проверяет необходимые системные возможности;
2. создаёт системного пользователя `dextr`;
3. создаёт каталоги конфигурации, состояния и журналов;
4. устанавливает программу;
5. устанавливает системную службу;
6. включает автоматический запуск;
7. запускает DEXTR Commander;
8. проверяет состояние службы.

## Проверка

```bash
systemctl is-enabled dextr-http.service
systemctl is-active dextr-http.service
```

Ожидается:

```text
enabled
active
```

## После перезагрузки

```bash
sudo reboot
```

После загрузки:

```bash
systemctl is-active dextr-http.service
```

Состояние должно снова быть `active`.

## Установка из исходников

Для разработчика:

```bash
cargo build --release --bin dextr-http
sudo ./install.sh
```

## Удаление

```bash
sudo ./uninstall.sh
```

Удаление программы и службы не удаляет данные автоматически.

## Важное замечание

Установка сама по себе не открывает DEXTR Commander в Интернет. Удалённый доступ должен быть настроен отдельно и защищён соответствующей политикой доступа.
