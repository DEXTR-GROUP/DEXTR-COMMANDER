# Установка DEXTR Commander

## Обычная установка

Обычная установка должна использовать готовый официальный выпуск DEXTR Commander. Сборка из исходников требуется разработчикам.

После получения архива выпуска:

```bash
tar -xzf dextr-commander-*.tar.gz
cd dextr-commander-*
sudo ./scripts/install.sh
```

Установщик:
1. проверяет Linux;
2. проверяет наличие готовых программ;
3. создаёт системную группу и пользователя `dextr`;
4. создаёт каталоги конфигурации, состояния и журналов;
5. устанавливает программы;
6. устанавливает системную службу;
7. включает автоматический запуск;
8. запускает службу;
9. проверяет её состояние.

После успешной установки DEXTR Commander запускается автоматически после каждой загрузки компьютера.

## Установка из другого каталога

```bash
sudo ./scripts/install.sh /path/to/release
```

В каталоге должны находиться `dextr-commander` и `dextr-http`.

## Проверка

```bash
systemctl is-enabled dextr-http.service
systemctl is-active dextr-http.service
```

Ожидается:

```text
enabled
active
```

Проверка после перезагрузки:

```bash
sudo reboot
```

После загрузки:

```bash
systemctl is-active dextr-http.service
```

## Удаление

```bash
sudo ./scripts/uninstall.sh
```

Исполняемые файлы и служба удаляются. Конфигурация, состояние и журналы сохраняются, чтобы не потерять данные при переустановке.

## Текущее состояние распространения

Установщик уже готов для каталога с готовыми бинарными файлами. Следующий отдельный этап — официальные релизы с готовыми файлами и контрольными суммами. До появления первого официального выпуска бинарные файлы необходимо получить из сборки проекта.

## Безопасность

Служба работает от имени отдельного пользователя `dextr`. Установщик не предоставляет удалённый доступ автоматически. Удалённое подключение настраивается отдельно.
