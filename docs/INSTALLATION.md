# Установка

Эта инструкция описывает установку DEXTR Commander на Linux из дерева проекта.

## Быстрая установка

Соберите сервер:

```bash
cargo build --release --bin dextr-http
```

Запустите установщик:

```bash
sudo ./install.sh
```

Установщик автоматически:
1. проверяет наличие systemd;
2. создаёт системную группу `dextr`;
3. создаёт отдельного системного пользователя `dextr`;
4. создаёт каталоги конфигурации, состояния и журналов;
5. устанавливает программу;
6. устанавливает системную службу;
7. включает автоматический запуск;
8. запускает службу;
9. проверяет её состояние.

## Проверка

```bash
systemctl is-enabled dextr-http.service
systemctl is-active dextr-http.service
systemctl status dextr-http.service --no-pager
```

Ожидается:

```text
enabled
active
```

## Проверка после перезагрузки

```bash
sudo reboot
```

После загрузки:

```bash
systemctl is-active dextr-http.service
```

Состояние должно быть `active`.

## Удаление

```bash
sudo ./uninstall.sh
```

Программа и служба удаляются, но каталоги конфигурации, состояния и журналов сохраняются, чтобы не уничтожить данные без явного решения администратора.

## Важно

Текущий установщик работает из исходного дерева и поэтому требует предварительной сборки Rust.
